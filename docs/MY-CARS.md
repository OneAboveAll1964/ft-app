# Мои авто

Раздел хранит отдельные настройки подключения, изображения, звука, Android Auto
и автомобильного экрана для каждой машины. Выбор автомобиля сам по себе не
запускает соединение; кнопка «Подключить» выбирает профиль и запускает его протокол.
Для добавления, выбора или удаления машины требуется полностью отключить соединение.
Настройки языка и оформления телефона остаются общими.

При первом запуске прежние настройки становятся профилем «Мой автомобиль» без
переноса и сброса существующего сопряжения. Новые автомобили начинают с настроек
по умолчанию и проходят собственное сопряжение. Удаление профиля очищает его настройки,
ICCOA-сопряжение, калибровку касаний и фотографию фона. Перед удалением выбранной
машины нужно выбрать другую.

Экспорт JSON сохраняет выбранную машину и общие настройки приложения. Он не
содержит список машин и ключи сопряжения. Импорт меняет выбранный профиль; для него
также требуется отключение. Старые файлы настроек поддерживаются.

## Иллюстрации

В `app/src/main/res/drawable-nodpi/car_*.webp` находятся пять иллюстраций,
созданных встроенным ImageGen: RAV4 XA50, RAV4 XA60, Corolla, Camry и хэтчбек.
WebP сохраняет прозрачность; ширина ограничена 800 px. Общий размер около 280 КБ.
Универсальный SUV использует XA50, седан — Corolla, другой автомобиль — хэтчбек.
Это иллюстрации для профиля, а не точные каталожные фотографии комплектаций.

Общий запрос: одна целая белая машина, передний ракурс в три четверти вправо,
тёмные стёкла, серебристые колёса, мягкий студийный свет, прозрачный фон,
без надписей, с полями вокруг машины, аккуратная реалистичная 3D-иллюстрация.
Варианты: RAV4 XA50 2019–2025; RAV4 XA60 2026 с новой передней частью и фарами;
Corolla E210 sedan; Camry XV70; универсальный пятидверный хэтчбек без эмблем.

Для формы передней части XA60 использован официальный референс Toyota:
[World Premiere of the All-New RAV4](https://global.toyota/en/newsroom/toyota/42758168.html).
Иллюстрации созданы отдельно, исходная фотография в APK не входит.
