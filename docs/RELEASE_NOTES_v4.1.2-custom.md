# FT v4.1.2-custom (Build 199)

Кастомная сборка FT для мультимедийных систем Toyota / FAW CarLife и ICCOA CarLink.

### Что нового:
1. **Стабильное подключение CarLife по Wi‑Fi Direct, даже если CarLife на ГУ запущен заранее:**
   - Если головное устройство уже подняло свою группу Wi‑Fi Direct (`groupOwner = true`), FT сразу подключается клиентом (`ownerIntent = 0`), не конфликтуя за роль Group Owner и не зависая в `INVITED`.
   - Ограничено ожидание Bluetooth SPP-анонса в `CarFinder.restart()` (`30` секунд вместо бесконечного цикла): если CarLife на ГУ запущен раньше и не перезванивает по SPP, FT возобновляет P2P-поиск и `autoMatch`.
   - Добавлена гарантированная очистка состояния `recovery` в блоке `finally`.

2. **Чистое закрытие каналов при разрыве связи (`WifiChannelLink`):**
   - `CarLifeWriter` закрывается сразу при завершении `readLoop` до переключения на главный поток, а запись в уже закрытый сокет больше не засыпает лог стектрейсами `SocketException: Socket closed`.
