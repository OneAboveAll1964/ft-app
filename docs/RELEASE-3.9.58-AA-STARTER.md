Тестовая сборка FT 3.9.58-aa-starter (172).

Изменения:
- Добавлена отдельная служба специальных возможностей «FT — запуск Android Auto». Пользователь включает её самостоятельно; служба касаний автомобиля больше не используется для запуска сервера AA.
- Запуск через меню AA ограничен коротким запросом, проверкой пакета и окна, состоянием блокировки и подтверждением результата. Удалены координатные shell-нажатия, автоматическое включение службы и попытки разблокировки из пути запуска AA.
- Прямой root-запуск ограничен известным серверным сервисом AA; ожидание команд ограничено и отменяется вместе с запросом.
- Добавлена настройка «Проверять и запускать Android Auto перед подключением» для CarLife/Baidu и ICCOA. Она выключена по умолчанию и сохраняется отдельно для каждого автомобиля.
- При неудачной подготовке подключение к машине продолжается, а FT показывает причину. Транспортные повторы используют результат подготовки; отключение ожидающего USB отменяет её.
- Улучшено восстановление поиска Baidu при незавершённом предыдущем согласовании Wi-Fi Direct. Исправление проверено модульными тестами; результат на конкретной машине ещё предстоит проверить.

Настройка: **Настройки → Автомобиль и подключение → Проверять и запускать Android Auto перед подключением**.

Без root сначала вручную включите режим разработчика Android Auto и отдельную службу **«FT — запуск Android Auto»** в специальных возможностях телефона. Для действий помощника телефон должен быть разблокирован. Автоматическое открытие AA после подключения автомобиля настраивается отдельно.

Ограничение безопасности: фильтр пакета ограничивает события службы, а проверки кода исключают обход содержимого чужих окон. Это не системная песочница всего FT. Отдельный помощник не выполняет жесты. Подробности: [описание реализации](AA-STARTER-2026-11-04.md).

Проверки: **733 модульных теста в 113 наборах, без ошибок и пропусков**. Проведены ревью Astra и повторное ревью трёх исправлений: ограничение root-команд, отмена при USB detach и изоляция отказа подготовки между машинами. Release-сборка и `lintVitalRelease` прошли успешно; подпись APK проверена через `apksigner` и совпадает с подписью опубликованной сборки 3.9.57 (171).

Сборка предназначена для проверки на телефоне и в автомобиле. Реальные подписи меню AA и ограничения прошивок модульными тестами не проверены. Отложенная проблема смещения касаний ICCOA внутри Android Auto в этой версии не исправлена.

Установка: скачать APK из Assets релиза и установить на телефон. Рядом опубликована контрольная сумма SHA-256.
