# Полный отчёт Android после сбоя ICCOA на OnePlus 12

Нужны два файла с одной попытки: системный **bugreport-…zip** и обычный **FT-report-…zip**. Системный отчёт содержит журналы Android и состояние системных служб; встроенный отчёт FT помогает сопоставить их с этапами подключения. Компьютер и установка дополнительных приложений для этого способа не требуются.

## 1. Заранее откройте меню разработчика

1. Откройте **Настройки / Settings → Об устройстве / About device → Версия / Version**.
2. Найдите **Номер версии / Version No. / Номер сборки / Build number** и нажмите на него семь раз. Если телефон попросит код разблокировки экрана, введите его на телефоне. Должно появиться сообщение о включении режима разработчика. Если режим уже включён, переходите дальше.
3. Вернитесь в настройки. Через поиск настроек найдите **Для разработчиков / Developer options**. На OxygenOS этот раздел может находиться в **Система и обновления / System & updates** либо **Дополнительные настройки / Additional settings**. Названия и расположение зависят от прошивки.
4. Найдите **Отчёт об ошибке / Создать отчёт об ошибке / Take bug report / Bug report**. Пока не запускайте сбор: сначала нужно воспроизвести ошибку.
5. Если такого пункта нет или он недоступен, отправьте разработчику снимок этого меню. Не устанавливайте случайные программы для сбора логов.

## 2. Воспроизведите сбой один раз

1. Оставьте автомобиль на стоянке с включённой мультимедиа. На телефоне должны быть включены Bluetooth, Wi-Fi и местоположение.
2. На Toyota откройте **ICCOA Carlink**. В FT выполните обычное подключение: **Connect**, текущий шестизначный код с экрана Toyota, подтверждение Wi-Fi, если Android его запросит.
3. После появления ошибки сразу сделайте снимок FT и фотографию экрана Toyota. Запишите время до минуты, например: **«Ошибка в 19:12»**, и укажите, был ли это первый запуск подключения или повторная попытка после предыдущего обрыва.
4. До завершения сбора отчёта не перезагружайте телефон или мультимедиа, не нажимайте **Остановить / Force stop** для FT, не выключайте Wi-Fi и Bluetooth и не начинайте следующую попытку подключения. Перейти из FT в настройки можно.

## 3. Сразу создайте системный отчёт

1. Откройте подготовленное меню **Для разработчиков / Developer options**.
2. Нажмите **Отчёт об ошибке / Take bug report**.
3. Если телефон предлагает тип отчёта, выберите **Полный / Full report**. Нажмите **Создать / Report**. Если выбора типа нет, запустите доступный отчёт.
4. Подождите несколько минут. Ход сбора или готовность отчёта можно проверить в шторке уведомлений. Не начинайте новое подключение, пока отчёт собирается.
5. Когда появится уведомление **«Отчёт об ошибке готов / Bug report captured»**, нажмите на него и отправьте разработчику полученный **ZIP-файл как документ**. Обычно имя начинается с **bugreport-**. Распаковывать файл не нужно.
6. Затем вернитесь в FT и нажмите значок отправки рядом с **Send report to the developer →**. Отправьте также **FT-report-…zip**, снимок FT, фотографию Toyota и время ошибки.

Пример сообщения:

> FT 140, OnePlus 12 Global, Toyota XA60. Ошибка в 19:12. Первая / повторная попытка. На Toyota было: __. Изображение FT появилось / не появилось. Прилагаю bugreport и отчёт FT с этой попытки.

Системный отчёт может содержать сведения об устройстве и сетях, поэтому отправьте его разработчику лично.

Собирать отчёт лучше сразу после первого обрыва, а не после нескольких повторных попыток: старые записи журналов постепенно вытесняются. Отчёт Android поможет проверить события на телефоне, но не заменяет журналы самой Toyota и не гарантирует объяснения её внутреннего кода ошибки.

Официальные инструкции: [сбор отчёта Android](https://developer.android.com/studio/debug/bug-report) и [включение меню разработчика](https://developer.android.com/studio/debug/dev-options).
